## 📖 About

Village Finder predicts all village locations from the world seed, categorising them by biome type and highlighting the nearest ones with distance and bearing.

---

## ✨ Features
<a name="features"></a>

- **All Village Types** — plains, desert, savanna, taiga, snowy.
- **Seed-Based Prediction** — no exploration required.
- **Biome Filter** — search for a specific village type.
- **Distance & Bearing** — HUD arrow points to nearest.
- **Map Markers** — pins on minimap per village.
- **Iron Golem Count** — estimated golem spawns per village.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
